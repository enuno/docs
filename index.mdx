UniFi MCP Server is an open-source [Model Context Protocol](https://modelcontextprotocol.io) (MCP) server that connects AI assistants directly to your UniFi network infrastructure. Once installed, you can manage devices, configure networks, set firewall rules, monitor traffic, and automate backups — all through natural language conversations with your AI assistant.

## What you can do

With UniFi MCP Server, your AI assistant gains the ability to interact with your entire UniFi network. You can ask it to list all connected devices, block a suspicious client, create a guest WiFi network, set up firewall rules, or generate a network topology diagram — and it will do so using the official UniFi API.

## Get started in 3 steps

<Steps>
  <Step title="Get your UniFi API key">
    Log in to [unifi.ui.com](https://unifi.ui.com), navigate to **Settings → Control Plane → Integrations**, and create an API key. Save it — it's shown only once.
  </Step>
  <Step title="Install the server">
    ```bash
    pip install unifi-mcp-server
    ```
    Or use Docker: `docker pull ghcr.io/enuno/unifi-mcp-server:latest`
  </Step>
  <Step title="Connect your AI assistant">
    Add the server to your MCP client configuration (Claude Desktop, Cursor, or any MCP-compatible client) and start managing your network through natural language.
  </Step>
</Steps>

<Note>
  For full network management capabilities — creating networks, configuring firewalls, and controlling devices — use the **Local Gateway API** mode (`UNIFI_API_TYPE=local`). Cloud API modes are limited to read-only site statistics.
</Note>
