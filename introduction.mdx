UniFi MCP Server is an open-source server that implements the [Model Context Protocol](https://modelcontextprotocol.io) (MCP) — a standard that lets AI assistants use external tools and data sources. Once connected, your AI assistant can read and control your UniFi network infrastructure directly, using the official UniFi API.

MCP works like a bridge: your AI assistant sends requests to the MCP server, which translates them into UniFi API calls and returns the results. You interact entirely through natural language — no scripting or API knowledge required.

## Who it's for

UniFi MCP Server is built for anyone who manages a UniFi network and wants to use an AI assistant to speed up routine tasks. Whether you're a home lab enthusiast, a network engineer, or an IT administrator managing multiple sites, the server lets you interact with your network the way you'd have a conversation.

## Three API modes

UniFi MCP Server supports three ways to connect to your UniFi infrastructure. The right choice depends on what you need to do:

- **Local Gateway** — Direct access to your UniFi gateway over your local network. All 77 tools are available, including full read and write access to devices, networks, and firewall rules. This is the recommended mode for most users.
- **Cloud v1** — Connects to the official stable UniFi cloud API. Limited to read-only site statistics. Rate limit: 10,000 requests per minute.
- **Cloud EA** — Connects to the Early Access cloud API. Limited to read-only site statistics. Rate limit: 100 requests per minute.

See [API modes](/api-modes) for a full comparison and configuration instructions.
